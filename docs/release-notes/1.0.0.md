Morph 1.0: drag files, hold a key, drop on a wheel to convert, edit or act on them. Windows 11, offline, free and open source (MIT).

**Install:** download `Morph-1.0.0-setup.exe`, run it (no admin needed). Morph isn't code-signed yet, so SmartScreen shows
"Windows protected your PC": click **More info → Run anyway**. To check the download: `Get-FileHash Morph-1.0.0-setup.exe`
and compare with `Morph-1.0.0-setup.exe.sha256`.

### New since 0.9

- **Explorer menu:** right-click files or folders → Show more options → **Morph** opens the wheel on them. Starting Morph again
  opens Settings instead of a second copy.
- **PDF to Markdown, Excel and PowerPoint.** Markdown and Excel are beta (Excel takes the PDF's ruled tables); PowerPoint makes
  one slide per page, as a picture.
- **Faster big PNGs:** a 12-megapixel photo to PNG takes about 2 s instead of 12, and the file is no bigger.
- **Accessibility:** follows Windows' text size; Narrator reaches the wheel, the editors' crop box, timelines and page grid,
  and reads changing text; high contrast uses the system colours.
- **Awkward files:** very long folder paths and names in any script (emoji, Cyrillic, CJK) work in every tool; a read-only
  folder sends results to Downloads and says so; OneDrive files that are only in the cloud are downloaded first, with a plain
  message if that fails.
- **Report a problem** (tray menu, Settings → About) opens a filled-in GitHub issue in your browser; crashes are saved locally
  and never sent by themselves.
- Third-party notices completed, with a source code offer for FFmpeg, libheif/libde265 and LibreOffice.

### Known limits

- Not code-signed (see Install). The Windows 11 right-click menu entry is under "Show more options" until it is.
- JPG → PNG of a 12-megapixel photo is about 1.8 s on a 2018 laptop, a little over the 1.5 s target.
- Optional packs: the Office pack (~490 MB, LibreOffice) is needed for slides, spreadsheets, DOC and OpenDocument only
  without Microsoft Office; the Background pack (~165 MB) for Remove background. Morph asks before downloading either.
